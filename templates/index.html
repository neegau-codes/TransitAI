Future API Integration Architecture

This system uses a decoupled Provider Architecture. You can easily plug in real-world APIs like Indian Railways (NTES), Kochi Metro, or bus reservation services. To integrate real APIs, simply subclass the TransportProvider interface and override the get_all_segments() method in the providers/ directory.
